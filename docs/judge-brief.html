The work ships when the invoice clears.

Four AI agents quote a job, bill it through real PayPal invoices, chase the payment, and release the work only when PayPal says it's paid. A client's own AI assistant can hire the agency over MCP. A person approves every money move.

01Try it in two minutes · no login

  1. Fill example, any name and an @example.com email, Get a quote. The Scoper prices it under a hard cap.
  2. Approve · 50% deposit first. Real PayPal sandbox invoices are created and sent; their ids show on the job.
  3. Send reminder now. The Collector writes it; PayPal's remind API sends it.
  4. Demo: pay deposit, then watch the watermarked preview appear. Demo: pay balance unlocks Download.
  5. Try a prompt injection. Hidden instructions are listed, struck through and ignored.
  6. Ledger tab (AG Grid), AI agents tab (MCP URL), then Refund.

02The loop

  1. Scoper (Gemini, structured output): request → fixed-price quote, capped in code, plus a list of injected instructions it ignored.
  2. A person approves: in full, or a 50% deposit first. Nothing reaches PayPal before this.
  3. Biller (tool calling): one forced call drafts the invoice; the code sends it.
  4. Collector: reminders on a schedule, at most three, through PayPal.
  5. Builder: starts when PayPal reports payment. Deposit → watermarked preview; balance → final files.
  6. Until then the work answers HTTP 402 Payment Required with a machine-readable PayPal pay link.

03PayPal · 10 endpoints, hand-written REST

  • Invoicing v2: create, send, get, remind, cancel, record payment, record refund.
  • Payments v2: refund a capture. Webhooks: signature verification. OAuth 2.0.
  • Deposit plans use partial payments, or a deposit invoice plus a balance invoice where the merchant's country doesn't allow them (ours didn't).
  • The job id is the PayPal-Request-Id, so retries never double-invoice.

04AI and agentic commerce

  • Gemini via the Vercel AI SDK: gemini-flash-latest → flash-lite-latest → 3.8-flash, with timeouts and a rest period for busy models.
  • MCP server (official TypeScript SDK): request_quote, get_job, list_jobs. A buyer's AI can ask and track; it has no tool to approve, pay, cancel or refund.
  • Failed builds retry on their own, up to five times.

05Safety by design

  • Amounts and recipient come from the approved quote in server state, never from model output (CaMeL, arXiv 2503.18813).
  • Untrusted text can't trigger consequential actions (arXiv 2506.08837).
  • Refund and cancel have no AI tool. Webhooks only trigger a fresh read from PayPal.
  • Builder HTML runs in a sandboxed iframe under a strict CSP.

06Sponsor tools · verified

  • AG Grid: the receivables desk. Quick views, aging buckets, pinned totals that follow filters, bulk Remind selected, CSV export, themed.
  • Render: one-click Blueprint (render.yaml), auto-deploy from main, health check.
  • 10 of 10 tests pass (npm test). Whole flow run on the live sandbox, Nov 12, 2026.
