How it works
  1. Scoper agent prices the request (hard cap in code)
  2. You approve, in full or with a 50% deposit
  3. Biller agent sends a real PayPal sandbox invoice
  4. Collector agent chases payment on its own
  5. Builder agent delivers once PayPal says paid
